Onboard a machine Bring your hardware online on capability.network in about 60 seconds.

Type the make/model, paste a description, or add a photo of the device label/screen. Works on every instrument — known adapters auto-fill, unknowns hand off to your LLM.

Run this on the machine that can reach your hardware over the LAN:

curl -fsSL https://capability.network/install.sh | bash

It will:

  1. Check for python3 / pip / git
  2. Install pcc-node from source (covers all current adapters)
  3. Ask you for the instrument URL + credentials
  4. Auto-provision a PCC API key
  5. Generate a KERNEL_CONFIG and start the kernel daemon

When done, your kernel page will be at capability.network/operator/<your-kernel-id> and you'll be accepting jobs from any customer on the network.

230+ tools, role-aware system prompt, install recipes baked in. Paste into Claude / ChatGPT / Cursor / any LLM with shell access — it bootstraps onboarding end-to-end.

~207 KB. Once copied, paste into the LLM and tell it what you have — for example “I have a [your device] at http://192.168.1.50, here are the credentials. Register it and start the kernel daemon.” The LLM picks the OPERATOR role from the prompt and walks the rest. If your device isn't on a first-class adapter yet, the LLM scaffolds one from the API docs.
