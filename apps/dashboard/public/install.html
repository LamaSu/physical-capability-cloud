Onboard a machine Bring your hardware online on capability.network in about 60 seconds.

Run this on the machine that can reach your hardware over the LAN:

curl -fsSL https://capability.network/install.sh | bash -s -- --vendor=hamilton

It will:

  1. Check for python3 / pip / git
  2. Install pcc-node from source (covers all current adapters)
  3. Ask you for the instrument URL + credentials
  4. Auto-provision a PCC API key
  5. Generate a KERNEL_CONFIG and start the kernel daemon

When done, your kernel page will be at capability.network/operator/<your-kernel-id> and you'll be accepting jobs from any customer on the network.
