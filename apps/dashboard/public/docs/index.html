What is PCC?

PCC is a verifiable on-chain skill wrapper for any physical capability. Machines register what they can do as soulbound NFTs (Metaplex Core). Agents discover, price, and orchestrate those skills through smart contracts with milestone escrow.

Quick Start: Connect Your Agent

1

Get the Tool Spec

Fetch PCC's 28 tool definitions — they tell your agent what it can do on the network:

curl https://YOUR_DEPLOYMENT/api/agent/tools.json
2

Feed Tools to Your Agent

If you're using Claude:

import Anthropic from "@anthropic-ai/sdk";

const client = new Anthropic();
const toolSpec = await fetch("https://YOUR_DEPLOYMENT/api/agent/tools.json").then(r => r.json());

const response = await client.messages.create({
  model: "claude-sonnet-4-20250514",
  max_tokens: 4096,
  system: "You are connected to the PCC manufacturing network. Use the available tools to help the user.",
  tools: toolSpec.tools,
  messages: [{ role: "user", content: "What capabilities are available?" }],
});

If you're using OpenAI, convert input_schema to parameters in the function calling format.

3

Execute Tool Calls

When your agent returns a tool_use block, execute it against PCC's API:

// Agent returns: { name: "list_kernels", input: {} }
const result = await fetch("https://YOUR_DEPLOYMENT/api/kernels").then(r => r.json());

// Feed the result back to your agent as a tool_result
4

Or Use the Dashboard

Open the PCC Dashboard, click "Connect my agent", enter your API key, and chat directly. The dashboard handles tool execution automatically.
